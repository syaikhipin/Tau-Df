# Data

`taiwan_credit.npz` contains the feature matrix `X` and binary target `y` for the
Taiwan credit-card default dataset:

- I-C. Yeh and C.-h. Lien, "The comparisons of default forecasting by
  probabilistic neural networks and other classification techniques,"
  *Expert Systems with Applications*, 36(2):6119-6127, 2009.
- UCI Machine Learning Repository, dataset ID 350.

The file is copied unchanged from the MIT-licensed `lkbook` package
(https://github.com/asudjianto-xml/Learned-Kernel); the upstream license is in
`LICENSE-lkbook`. The dataset is public and de-identified.

California housing is downloaded at runtime by scikit-learn and is not stored
here.
